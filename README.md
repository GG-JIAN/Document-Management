# 课题组文献管理系统

基于 Python、Django 和 PostgreSQL 的课题组资料管理网页应用。

## 开发环境

- Python 3.10 或更高版本
- Django 5.2
- SQLite（本地开发默认）或 PostgreSQL（部署环境）

## Windows 本地启动

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

浏览器访问 http://127.0.0.1:8000/ 。本地开发服务器只用于开发，不用于正式部署。

### 同一局域网内的其他电脑临时访问

1. 在运行服务器的 Windows 电脑打开命令提示符，执行 `ipconfig`，记下正在使用的网卡 IPv4 地址，例如 `192.168.1.25`。
2. 在启动 Django 前，将该地址加入允许主机列表，然后监听所有网卡：

```powershell
$env:LAB_ALLOWED_HOSTS = "localhost,127.0.0.1,192.168.1.25"
.\.venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000
```

把示例地址替换成实际 IPv4。其他电脑访问 `http://192.168.1.25:8000/`。电脑重启或换网卡后，IPv4 可能变化，需要更新地址并重新启动服务器。

如果连接超时，在服务器电脑的 Windows 防火墙中为 TCP 8000 添加仅适用于可信的专用/域网络的入站规则；校园网也可能启用了设备隔离或不同网段访问限制，需要由网络管理员确认。不要在不可信的公共网络开放开发服务器。`runserver` 仅用于同一局域网的临时验证，不是正式部署方案。

## 首次账号与资料配置

1. 使用 `createsuperuser` 创建的账号登录 `/admin/`。
2. 先录入课题组成员，再创建普通用户账号。普通用户的用户名必须与成员姓名完全一致；管理员或超级管理员都可以绑定成员档案。
3. 超级管理员可在用户管理中把账号设为管理员。管理员可管理成员、项目、论文、关键词、专利和普通用户账号；不能调整用户角色。
4. 已绑定成员的普通用户登录后可在“资料申请”提交身份、邮箱、联系方式和在跟课题的变更，也可申请新增项目、论文或专利、申请修改自己关联的论文。申请项目、论文或专利时可附上相关文件；管理员或超级管理员通过后，资料会进入正式列表，附件会出现在对应条目的“相关资料下载”区域。
5. 多人提交同一条论文、项目或专利时，审核通过会优先匹配并复用已有条目，将申请成员和附件合并进去。论文按 DOI 优先、再按规范化标题匹配；项目按标题匹配；专利按专利号优先、无专利号时按标题匹配。论文申请必须填写关键词，系统自动创建或复用关键词并完成分类；同一论文下相同内容的文件不会重复归档。已有非空信息会保留，新申请只补齐空字段。
6. 超级管理员可在用户列表的“设置新密码”入口为账号重设密码。系统只保存密码哈希，无法查看或还原用户原密码；重设操作会记入管理操作记录。
7. 超级管理员可在管理后台查看操作日志；管理员仅能审核申请，不能浏览完整操作日志。
8. 普通用户可在页面右上角选择“修改我的密码”，验证当前密码后设置新密码；新密码立即生效。

## 数据备份

在项目目录运行以下命令，会生成包含数据库和 `media` 上传目录的带时间戳 ZIP 备份：

```powershell
.\.venv\Scripts\python.exe manage.py backup_system
```

默认保存在项目的 `backups` 目录。备份包含数据库和 `media` 下的已审核附件及待审核申请附件。超级管理员登录后可通过“数据备份”页面立即创建、查看和下载备份，创建和下载动作都会写入操作日志；管理员及普通用户无权访问。正式部署建议把 Windows 环境变量 `LAB_BACKUP_DIR` 指向独立硬盘或受限访问的备份目录，并在 Windows 任务计划程序中每日运行上述命令。备份命令不会自动删除旧文件。

普通用户不能删除项目、论文、专利或其附件；管理员和超级管理员可在管理后台维护正式资料及附件。

单个附件默认最大 500 MB。可通过 Windows 环境变量 `LAB_MAX_MATERIAL_UPLOAD_SIZE` 调整上限，单位为字节。若部署时使用 IIS 或反向代理，也要把其单次请求大小限制设为不低于该值。

录入数据和修改角色前，建议先保留数据库备份。当前开发阶段使用 SQLite，生产部署前会切换到 PostgreSQL 并配置自动备份。
